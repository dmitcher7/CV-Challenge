# 🏆 Final Product & Evaluatie

Deze map bevat de definitieve, geteste en gevalideerde deliverables voor de **Computer Vision Challenge: Sports Vision & Tactical Mapping**.

## 📂 Structuur
* `app/`: Bevat het finale Streamlit dashboard (`app.py`), modules voor de pipeline en eventuele styling.
* `models/`: Bevat de finale fine-tuned YOLO gewichten (`best.pt`).
* `notebooks/`: Bevat de schone, reproduceerbare notebooks voor:
  1. `01_model_training_and_tuning.ipynb`
  2. `02_error_analysis.ipynb`
  3. `03_homography_and_mapping.ipynb`
