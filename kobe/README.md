# Kobe - Werkruimte

Welkom in de individuele werkmap van **Kobe Vandenberk**.

## 📌 Doel van deze map
* Persoonlijke experimenten, exploratory notebooks en tests.
* Lokale annotaties of tests met labeling tools.
* Experimenten met specifieke deelproblemen (bv. augmentatie strategieën of evaluatie metrics).

## 📂 Inhoud
* [`training/`](training/README.md): data-split, labelplanning, training, evaluatie en error analysis voor het YOLO-model.
* [`homography/`](homography/README.md): veldpunten aanklikken, homografie per frame (met controle op drift), tracking (ByteTrack + Kalman voor de bal) en de 2D-minimap.

> [!NOTE]
> Zodra een component stabiel en gevalideerd is, migreren we de finale code naar de centrale `Final/` map.
